# Repository rules

- This repository is `nickguletskii/jj-superpowers`. `obra/superpowers` is not its base repository.
- Never create pull requests targeting `obra/superpowers`.
- Target pull requests at `nickguletskii/jj-superpowers` and specify the repository explicitly; never rely on fork/upstream auto-detection.
- With GitHub CLI, use `gh pr create --repo nickguletskii/jj-superpowers` (plus the appropriate base and head).
- Before submitting a PR, verify that its base repository is `nickguletskii/jj-superpowers`; stop if it is not.
- Use jj for version control.
